# Медицина Пророка ﷺ — отдельное нативное Android-приложение

**СТАТУС: техническая preview-сборка, не полноценная копия установленного APK 1.0.0.**

В этом репозитории реализуется полностью нативный Android-интерфейс на **Kotlin и Jetpack Compose**.
Никаких WebView/HTML-экранов. Исходная работа с книге независима от встроенного модуля
`medicine` в `Xalidmuslim/AlFatiha-Native` («Компас сердца»). Его код не изменён.

## Источники
- Установленный native APK версии 1.0.0 пользователя: выявлены пакет `com.xalid.meditsinaproroka.nativeapp`, `assets/book.json` (111 глав, 15 тем, 98 средств, 39 лечебных ситуаций).
- Floot PWA с таким же названием: архивирована в **отдельной review-ветке** `archive/floot-web-source-20261008`, не является Kotlin-исходником APK.

## Почему другое имя пакета?
Для превью применяется `com.xalid.meditsinaproroka.nativeapp.preview`, чтобы оно
**могло стоять рядом с уже установленной версией** и не перезаписывать её данные.
Для безопасного обновления оригинала требуется исходный ключ подписи Android;
этот ключ пока не восстановлен.

## Полный текст и проверка
`app/src/main/assets/book_index.json` содержит только сведения о структуре.
Полная пользовательская книга `book.json` **не публикуется в открытом репозитории**
без отдельного согласования прав на распространение.
Пока `book.json` отсутствует, программа честно показывает сообщение о недоступности текста.

### Как включить полный текст в установленном APK, без раскрытия его в GitHub
1. Скачайте оригинальный `book.json`, извлечённый **из вашего установленного APK 1.0.0**.
   Файл передаётся владельцу отдельно и НЕ публикуется в этом репозитории.
2. Скачайте APK тестовой нативной версии из **GitHub Actions → Artifacts** и установите рядом с версией 1.0.0.
3. На главной нажмите «Импортировать книгу из файла JSON» и выберите `book.json` в папке «Загрузки».
4. Приложение проверит структуру (111 глав, 15 тем, 98 средств, 39 ситуаций, не менее 2500 текстовых блоков)
   и сохранит содержимое в **закрытое локальное хранилище Android**.
5. Дальнейшее чтение, поиск и закладки работают офлайн, даже если файл удалён из «Загрузок».

Если импорт ошибочный, прежнее содержимое НЕ заменяется. Чтение не передаёт текст на сервер.
До завершения тестирования установленную рабочую версию 1.0.0 удалять нельзя.

Для локальной сборки с уже встроенной пользовательской книгой можно поместить файл
`app/src/main/assets/book.json` (игнорируется Git) и запустить
`gradle :app:assembleDebug` с JDK 17 и Android SDK 35.

## Разработка
Работа ведётся в отдельной ветке для проверки, без автоматического объединения с main.
Любой рефакторинг проверяйте на сохранность текста, переходов, настроек и закладок.
