# Медицина Пророка ﷺ — самостоятельный Android-проект из модуля

Код и ресурсы этого приложения **скопированы из существующего нативного модуля**
`Xalidmuslim/AlFatiha-Native/medicine` на фиксированном commit `1a1531a876b76c1b0d4cf53b9a0e9fb527d54b7a`.

Это не сгенерированная с нуля копия и не WebView: все 13 Kotlin-файлов, ресурсы,
шрифты, иконка и оригинальные данные `book.json` перенесены из существующего модуля.

Минимальные изменения для самостоятельного APK: модуль `com.android.library`
стал Android-приложением, появился LAUNCHER, а переходы в разделы "Компаса сердца"
заменены локальной навигацией (главная, темы, поиск, закладки, ещё).
Исходный модуль "Компаса сердца" не изменён.

ВАЖНО: debug APK имеет отдельный package id `com.xalid.meditsinaproroka.nativeapp.modulecopy`
и должен установиться рядом с основной версией. Для обновления старого APK
без потери данных нужен тот же ключ подписи. Бинарная/визуальная идентичность
пока не подтверждена проверкой на реальном Android-устройстве.

Важно: проверьте право на повторную публикацию русского перевода. До подтверждения репозиторий не объединяем с основной веткой.
Оригинал уже находится в публичном репозитории источника; этот PR не объединяется автоматически.

## Плавный запуск — отдельная тестовая установка (2026-10-08)
- Вместо промежуточного «Открываем книгу…» используется системная SplashScreen с оригинальной иконкой, пока фоновая загрузка книги не завершится.
- Инициализация кэша книги начинается в `MedicineApplication` до создания главного экрана.
- Навигация с анимацией 220 мс (slide + fade) без пересчёта высоты содержимого.
- Тестовое `applicationId`: `com.xalid.meditsinaproroka.nativeapp.modulecopy.smooth`.
- Пакет отличается от предыдущего `modulecopy`, потому что Android debug APK, собранные в разных GitHub Actions, имеют разные подписи. Не удаляйте старое приложение ради теста; оно хранит свои закладки и прогресс.
- Это **отдельная тестовая установка**; её настройки не переносятся автоматически в основную версию.
