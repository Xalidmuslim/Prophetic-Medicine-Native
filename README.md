# Медицина пророка — самостоятельное нативное Android-приложение

Это **отдельный** проект, не встроенный модуль приложения «Компас сердца».

## Зафиксированные ограничения
- Не изменять исходники `Xalidmuslim/AlFatiha-Native` и каталог `medicine/` в нём.
- Не синхронизировать автоматически отдельное приложение с модулем в «Компасе сердца».
- Восстановить **последнюю действующую отдельную нативную версию**, сохранив тексты, дизайн, логику и навигацию.
- Пока исходный архив/репозиторий этой отдельной версии не найден, не подменять его встроенным модулем и не создавать вымышленную реализацию.
- После проверки оригинала настроить отдельную сборку APK через GitHub Actions и возможность работы через Codex Cloud.

## Статус
Репозиторий подготовлен, **исходники самостоятельного приложения пока не импортированы**.
