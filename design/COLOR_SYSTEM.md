# Медицина Пророка — Premium Minimalism source vectors

This folder contains original editable, resolution-independent SVG source for the
12 Android VectorDrawable images in `app/src/main/res/drawable`. It is intended
for designers and potential future iOS asset catalogs (no iOS project is included here).

Palette:
- Background `#F7F3EB`
- Surface `#FBF8F2`
- Natural green `#2F6A52`
- Deep green `#214B3D`
- Sage `#8FA48F`
- Muted gold `#C8A46A`
- Primary text `#1F1C19`
- Secondary text `#6E6A63`
- Border `#E7DED1`

Typography: Literata for literary headings; Inter and Manrope for UI; original reader font settings remain unchanged.

Assets are small vector paths rendered locally; no stock downloads, network or AI typography artifacts. For Android, VectorDrawable XML is used directly without converting to bitmaps, keeping edges crisp across screen densities.
